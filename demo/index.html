用鼠标选中下面任意一段英文（或一个单词），光标旁会出现一个 24px 的小图标；点击它打开翻译卡片。翻译来自本机 Chrome 内置模型，失败才降级到免费接口。

Sample text

The first rule of reading in a foreign language is to keep moving. If you stop at every unfamiliar word, you lose the thread of the argument, and the thread is usually the only thing worth following. A good tool should therefore be invisible until the moment you need it, and then answer in a fraction of a second.

This paragraph is here so that you have something to select. Select a single word like therefore or invisible to see the dictionary lookup, or select a whole sentence to see machine translation. The icon follows your cursor and never covers the text you just selected.

Why no AI call

Sentence translation here is handled by the browser's built-in translation model, which ships with Chrome and runs entirely on your machine. There is no API key, no account, no request leaving the device, and no per-character bill. If that model is unavailable, the demo falls back to a free public endpoint, and for single words it uses a free dictionary API that the nextai-translator project also relies on.

Try selecting this sentence to see how long it takes: The best interface is the one you forget you are using.
